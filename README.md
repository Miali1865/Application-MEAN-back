# 🚀 Partie backend du projet Garage 

Ce dépôt contient la partie backend du projet Garage, une application web de gestion de garage automobile.

Ce backend est développé avec la stack MEAN, en utilisant :

Node.js comme langage principal 

Express.js comme framework backend léger et rapide

MongoDB comme base de données NoSQL pour stocker les informations (véhicules, clients, interventions, etc.)

JWT (JSON Web Tokens) pour gérer l’authentification sécurisée via des tokens

API RESTful pour assurer la communication avec le frontend

Render comme plateforme de déploiement du serveur backend : [https://dashboard.render.com/](https://dashboard.render.com/)

🔗 Le dépôt du frontend est disponible ici : [https://github.com/Miali1865/Application-MEAN-front](https://github.com/Miali1865/Application-MEAN-front)
